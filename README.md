# FlowForge AI

AI-powered business workflow automation platform.

## Overview
FlowForge AI allows businesses to create and execute automated workflows using natural language instructions.

## Core Features
- AI-powered workflow generation
- Automated business operations
- Customer registration
- PayPal payment integration
- Automated email confirmations
- Business analytics dashboard

## Technology Stack
- Frontend: React, TypeScript
- Backend: Python, FastAPI
- AI Engine: Python
- Payment: PayPal
